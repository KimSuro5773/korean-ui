# korean-ui 명령어

korean-ui가 제공하는 명령어 세 개의 사용법입니다. 설치 방법과 `/config` 항목은 [저장소의 README](https://github.com/KimSuro5773/korean-ui#readme)를 참고하세요.

## 한눈에 보기

| 명령어 | 하는 일 |
|---|---|
| `/korean-ui-translate` | 번역되지 않은 문구를 모두 Haiku로 번역합니다. |
| `/korean-ui-translate <요청>` | 요청에 해당하는 문구만 골라서, 요청한 방식대로 번역하거나 고칩니다. |
| `/korean-ui-reset` | Haiku로 번역해서 저장한 문구를 모두 지웁니다. |
| `/korean-ui-reset <플러그인>` | 그 플러그인의 번역만 지웁니다. |
| `/korean-ui-status` | 번역 현황을 제공자별로 보여 줍니다. |

> [!WARNING]
> `/korean-ui-translate`는 사용자 계정으로 Haiku 모델을 호출하므로 사용량이 소모됩니다. `/korean-ui-reset`에서 "지우고 다시 번역"을 골랐을 때도 마찬가지입니다. `/korean-ui-status`는 Haiku를 호출하지 않습니다.

## `/korean-ui-translate`

### 인자 없이 실행

`/config`에서 번역하도록 켜 둔 항목 중에서 아직 번역문이 없는 문구를 모두 번역합니다.

```
/korean-ui-translate
```

- 번역하는 동안 입력창 아래에 `번역 중 50/121`처럼 진행 상황이 표시됩니다.
- 번역이 끝나면 `명령어 설명 12개, 설정 항목 3개를 번역했습니다.`처럼 결과를 알려 줍니다.
- 번역에 실패한 문구는 결과 끝에 실패 이유와 함께 표시하고, 다음에 실행할 때 다시 번역합니다. 같은 문구가 3번 실패하면 다음부터 건너뜁니다.
- Haiku에게는 설명 문장과 함께 명령어 이름과 그 명령어를 제공하는 플러그인 이름을 보냅니다. 짧고 모호한 설명도 뜻을 짐작해서 번역하게 하기 위해서입니다.

### 요청과 함께 실행

명령어 뒤에 원하는 것을 문장으로 쓰면, 그 요청에 해당하는 문구만 골라서 요청한 방식대로 번역합니다. 이미 번역된 문구도 고칠 수 있습니다.

```
/korean-ui-translate superpowers 플러그인만 번역해 줘
/korean-ui-translate /help 설명을 더 짧게 고쳐 줘
/korean-ui-translate git과 관련된 명령어의 설명을 명사형으로 끝내 줘
```

요청을 처리하는 순서는 다음과 같습니다.

1. Haiku가 요청에 해당하는 문구를 고릅니다. 이때 입력창 아래에 `대상 선택 중`이 표시됩니다.
2. 고른 문구 중에 이미 번역문이 있는 문구가 있으면, 대상을 보여 주고 확인을 받습니다.
3. 고른 문구만 요청한 방식대로 번역합니다.
4. 바뀐 문구를 결과로 보여 줍니다.

```
요청에 따라 명령어 설명 1개, 설정 항목 0개를 번역했습니다.
- /help: 도움말과 사용 가능한 명령어를 표시합니다 → 도움말 표시
```

알아 둘 점은 다음과 같습니다.

- **대상을 말하지 않은 요청**: `최대한 짧게 번역해 줘`처럼 번역 방식만 말하면 아직 번역되지 않은 문구만 대상이 됩니다. 이미 번역된 문구는 "고쳐 줘", "다시 번역해 줘"처럼 고치라는 뜻이 분명할 때만 대상이 됩니다.
- **확인 대화상자**: 이미 번역문이 있는 문구를 바꿀 때만 `기존 번역 1개를 다시 번역합니다: /help. 진행할까요?`라고 묻습니다. "취소"를 고르거나 대화상자를 닫으면 아무것도 바꾸지 않습니다. `claude -p`처럼 대화상자를 띄울 수 없는 실행에서는 기존 번역을 바꾸는 요청이 취소됩니다.
- **기본 번역표의 번역도 고칠 수 있음**: 요청으로 만든 번역은 "고친 번역"으로 따로 저장하고, 플러그인에 들어 있는 기본 번역표보다 먼저 표시합니다. 그래서 `/help` 같은 Claude Code 기본 명령어의 번역도 고칠 수 있고, 플러그인을 업데이트해도 고친 번역이 계속 표시됩니다.
- **번역문이 그대로인 경우**: 다시 번역한 결과가 지금 번역문과 같으면 저장하지 않고, 그 수를 결과에 알려 줍니다.
- **건너뛰던 문구**: 3번 실패해서 건너뛰던 문구도 요청으로는 다시 번역을 시도합니다.
- **대상 범위**: `/config`에서 꺼 둔 항목의 문구는 요청의 대상이 되지 않습니다. 다른 플러그인의 문구를 요청하려면 '다른 플러그인과 스킬 번역'을 먼저 켭니다.
- **`export`**: 인자로 `export` 한 단어만 쓰면 요청으로 처리하지 않습니다. Claude Code 기본 항목의 번역을 현재 폴더의 `korean-ui-ko.json` 파일로 내보내며, 기본 번역표를 관리할 때 쓰는 기능입니다.

## `/korean-ui-reset`

### 인자 없이 실행

Haiku로 번역해서 저장한 문구(자동 번역과 요청으로 고친 번역)와 3번 실패한 문구의 기록을 모두 지웁니다. 플러그인에 들어 있는 기본 번역표의 번역은 지워지지 않습니다.

```
/korean-ui-reset
```

지우기 전에 지울 개수를 보여 주고 다음 중 하나를 고르게 합니다.

| 선택지 | 동작 |
|---|---|
| 지우기 | 지우기만 합니다. |
| 지우고 다시 번역 | 지운 뒤 바로 `/korean-ui-translate`와 같은 번역을 실행합니다. |
| 취소 | 아무것도 지우지 않습니다. |

### 플러그인을 지정해서 실행

플러그인 이름을 쓰면 그 플러그인의 문구에 해당하는 번역과 실패 기록만 지웁니다.

```
/korean-ui-reset superpowers
/korean-ui-reset claude-code
```

- 이름은 `/korean-ui-status`의 "제공자" 열에 표시되는 이름을 씁니다. Claude Code 기본 항목은 `claude-code`, 직접 만든 스킬은 `user`입니다.
- `superpowers@marketplace`처럼 마켓플레이스 이름을 붙여도 되고, 대소문자가 달라도 됩니다.
- 일치하는 이름이 없으면 아무것도 지우지 않고, 지정할 수 있는 이름을 보여 줍니다.
- "지우고 다시 번역"을 고르면 그 플러그인의 문구만 다시 번역합니다.
- `/korean-ui-reset claude-code`를 실행하면 Claude Code 기본 항목의 자동 번역과 고친 번역이 지워집니다. 기본 번역표에 번역이 있는 문구는 기본 번역표의 번역이 다시 표시됩니다.

알려진 제약은 다음과 같습니다.

- 이번 세션에서 확인하지 못한 문구(이미 삭제한 플러그인의 번역 등)는 어느 플러그인의 것인지 알 수 없습니다. 이런 번역은 인자 없는 `/korean-ui-reset`으로만 지울 수 있습니다.
- 같은 문구를 다른 플러그인도 쓰고 있으면, 그 문구의 번역도 함께 지워집니다.
- 문구 하나만 다시 번역하려면 지우는 대신 `/korean-ui-translate /명령어 설명을 다시 번역해 줘`처럼 요청합니다.

## `/korean-ui-status`

번역 현황을 보여 줍니다. 인자를 받지 않고, Haiku를 호출하지 않습니다.

```
/korean-ui-status
```

```
버전: 0.2.0
설정: 기본 항목 번역 켜짐, 다른 플러그인과 스킬 번역 켜짐, 미번역 알림 켜짐

| 제공자 | 문구 | 기본 번역표 | 자동 번역 | 고친 번역 | 미번역 | 건너뜀 |
|---|---|---|---|---|---|---|
| claude-code | 167 | 160 | 3 | 2 | 2 | 0 |
| superpowers | 14 | 0 | 13 | 0 | 0 | 1 |

이번 세션에서 확인하지 못한 저장 번역: 5개
```

| 열 | 뜻 |
|---|---|
| 제공자 | 문구를 제공하는 주체입니다. Claude Code 기본 항목은 `claude-code`, 플러그인의 항목은 플러그인 이름, 직접 만든 스킬(사용자 스킬 폴더의 스킬)은 `user`입니다. |
| 문구 | 이번 세션에서 확인한 그 제공자의 문구 수입니다. 명령어 설명과 `/config` 항목을 합친 수입니다. |
| 기본 번역표 | 플러그인에 들어 있는 기본 번역표의 번역을 쓰는 문구 수입니다. |
| 자동 번역 | 인자 없는 `/korean-ui-translate`가 만든 번역을 쓰는 문구 수입니다. |
| 고친 번역 | 요청으로 만든 번역을 쓰는 문구 수입니다. |
| 미번역 | 번역문이 없는 문구 수입니다. |
| 건너뜀 | 번역문이 없고, 3번 실패해서 번역을 건너뛰는 문구 수입니다. |

- 문구 하나는 한 열에만 셉니다. 번역이 여러 곳에 있으면 화면에 적용하는 순서대로 고친 번역, 기본 번역표, 자동 번역 중 먼저 해당하는 열에 셉니다.
- 표는 저장된 번역을 기준으로 세고, `/config` 설정은 반영하지 않습니다. 예를 들어 '다른 플러그인과 스킬 번역'을 꺼 두면 다른 플러그인의 문구는 화면에 영어로 표시되지만, 저장된 번역이 있으면 표에서는 "자동 번역"으로 셉니다. 어떤 항목이 꺼져 있는지는 둘째 줄의 설정에서 확인합니다.
- 여러 제공자가 함께 쓰는 문구는 각 제공자의 행에 모두 셉니다.
- 마지막 줄은 저장되어 있지만 이번 세션에서 확인하지 못한 번역의 수입니다. 해당하는 번역이 없으면 이 줄은 표시되지 않습니다.
